## Modul 5 — Method dan Fungsi

Berisi implementasi konsep dasar method di Java meliputi void method, method dengan return value, parameter, variable scope, method overloading, dan penggunaan array sebagai parameter maupun return value.

**Latihan:**
- `LuasBangunDatar.java` — method `luasPersegiPanjang` & `luasLingkaran`
- `CekBilanganPrima.java` — method `isPrima` untuk mencetak bilangan prima 1–50
- `KonversiSuhu.java` — method overloading konversi Celsius ke Fahrenheit/Kelvin
- `CariNilaiUjian.java` — method `cariNilaiMinimum` & `cariNilaiMaksimum` dengan input Scanner
- `FilterNilaiUjian.java` — method `hitungTotal` & `filterDiAtasRataRata` dengan array return

**Tugas:**
- `KalkulatorMethod.java` — kalkulator interaktif dengan 7 operasi, overloading `tambah()`, dan riwayat hasil menggunakan array
